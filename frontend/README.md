# Pollify Frontend

This is the React frontend for the Pollify Live Polling Tool.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- WebSocket

## Features

- User login and signup
- Create polls
- View polls
- Vote on polls
- Share polls using a public link
- View live poll results
- Receive real-time result updates without refreshing the page
